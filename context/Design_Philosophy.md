# Design Philosophy

This website must NOT look AI generated.

The goal is to build something that feels like it was carefully designed by a professional UI/UX designer rather than automatically generated.

The design language should be:

- Clean
- Purposeful
- Minimal
- Sharp
- Modern
- Premium
- Human-designed

The event itself is futuristic, but the interface should remain simple and easy to scan.

Users should immediately understand the event without being overwhelmed by animations or visual effects.

---

## Visual Direction

Follow the uploaded event poster.

Do NOT copy it literally.

Instead, extend its visual language into a clean landing page.

Think:

- Apple
- Linear
- Vercel
- Stripe Docs
- Figma
- Notion

combined with

- Cyber Purple
- Dark UI
- Subtle Neon

---

## Avoid

Do NOT create:

- AI-looking gradients everywhere
- Giant glowing blobs
- Heavy glassmorphism
- Excessive blur
- Too many floating objects
- Fancy 3D effects
- Oversized shadows
- Overly rounded components
- Excessive motion
- Long marketing paragraphs
- Decorative elements without purpose

Every element must have a reason to exist.

---

## Preferred Style

Use:

✔ Sharp corners (10–14px)

✔ Thin borders

✔ Grid layouts

✔ Consistent spacing

✔ Clean typography

✔ Large whitespace

✔ Simple cards

✔ Subtle purple glow

✔ Small hover animations

✔ Professional iconography

Less is more.

---

## Corners

Avoid overly rounded cards.

Preferred:

Buttons

10px

Cards

12px

Inputs

10px

Images

12px

Timeline Cards

12px

Do NOT use 24px–40px radius.

---

## Shadows

Use very subtle shadows.

Instead of heavy shadows,

prefer

soft borders

combined with

low-opacity purple glow.

---

## Glass Effect

Use glassmorphism sparingly.

Only for

- Hero Card
- Countdown
- Registration CTA

Everything else should use solid dark surfaces.

---

## Typography

Large headings.

Short paragraphs.

Maximum

2–3 lines per paragraph.

Avoid large blocks of text.

Make content easy to scan.

---

## Layout

Every section should have a clear purpose.

Preferred order:

Hero

↓

About

↓

Timeline

↓

Competition

↓

Evaluation

↓

Badge System

↓

FAQ

↓

Register

Avoid unnecessary filler sections.

---

## Motion

Animations should feel natural.

Use Framer Motion only for:

Fade In

Small Slide

Hover Lift

Button Feedback

Avoid:

Huge page transitions

Rotating objects

Continuous floating animations

Parallax everywhere

Excessive motion.

---

## Components

Every component should feel handcrafted.

Spacing should be consistent.

Alignment should be pixel perfect.

Nothing should look auto-generated.

---

## Mobile

Desktop-first.

Then optimise for:

Tablet

Mobile

without changing the visual identity.

---

## Overall Feeling

The website should feel like

"a premium event microsite"

instead of

"a flashy AI landing page."

Professional.

Minimal.

Memorable.

Confident.

Not noisy.
